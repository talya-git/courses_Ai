# אתר הקורסים: מדריך הקמה

© כל הזכויות שמורות ל־TALYA TOLEDANO

האתר מנהל את הקורסים שלך. יש בו קורסים, הרצאות, מצגות, חומרי לימוד, תרגילים והגשות. אפשר לראות בו גם מי צפתה בכל הרצאה. רק תלמידות שאישרת יכולות לראות את הקורסים. נכנסים עם מייל וסיסמה.

**העלות: 0 ₪.** האתר יושב ב-GitHub Pages, והכניסה והנתונים נשמרים ב-Supabase. לשניהם יש תוכנית חינמית שמספיקה לקורסים.

---

## לפני הכול: לראות את האתר במחשב

אפשר לראות את האתר עוד לפני כל ההקמה. בקובץ `config.js` כתוב `demo: true`, ולכן האתר עובד עם נתוני דוגמה.

הקבצים צריכים "שרת" קטן כדי לעבוד, ולכן לחיצה כפולה על `index.html` לא מספיקה. הדרך הכי פשוטה:
1. להתקין את [VS Code](https://code.visualstudio.com), ובתוכו את התוסף **Live Server**.
2. לפתוח את התיקייה, ללחוץ קליק ימני על `index.html` ולבחור **Open with Live Server**.

בפס הצהוב למעלה יש כפתור "לראות כמו תלמידה", שמראה איך האתר נראה לתלמידה.

---

## שלב 1: לפתוח פרויקט ב-Supabase (בסיס הנתונים והכניסה)

1. נכנסים ל-[supabase.com](https://supabase.com), לוחצים **Start your project** ונרשמים (אפשר עם GitHub).
2. **New project**. שם: למשל `courses`. בוחרים סיסמה לבסיס הנתונים ושומרים אותה. Region: **Central EU (Frankfurt)**, הכי קרוב לישראל.
3. מחכים כדקה שהפרויקט יוקם.

### בניית בסיס הנתונים
1. בתפריט מימין: **SQL Editor** ‹ **New query**.
2. פותחים את הקובץ `supabase/schema.sql`. **בשורה האחרונה מחליפים** את `your.email@gmail.com` במייל שלך, באותיות קטנות.
3. מעתיקים את כל הקובץ, מדביקים ולוחצים **Run**. צריך להופיע `Success`.

הקובץ בונה את הטבלאות ואת כללי האבטחה (תלמידה רואה רק את הקורסים שלה, ולא יכולה לתת לעצמה ציון). הוא גם יוצר מקום לשמירת המצגות, ומגדיר אותך כמנהלת הראשית. מותר להריץ אותו שוב, זה לא מוחק נתונים.

## שלב 2: לחבר את האתר ל-Supabase

1. ב-Supabase: **Project Settings** ‹ **API** (לפעמים נקרא **Data API** / **API Keys**).
2. מעתיקים שני דברים:
   - **Project URL**, שנראה כמו `https://abcdefgh.supabase.co`
   - המפתח **anon / public**
3. פותחים את `config.js` וממלאים:

```js
supabaseUrl: 'https://abcdefgh.supabase.co',
supabaseAnonKey: 'eyJhbGciOi...',
demo: false,
```

המפתח `anon` מותר לפרסום. מה שמגן על הנתונים הם כללי האבטחה מהשלב הקודם. **אף פעם לא להכניס לאתר את המפתח `service_role`.**

---

## שלב 3: להעלות את האתר ל-GitHub Pages

1. נרשמים ל-[github.com](https://github.com).
2. **New repository**. שם: למשל `courses`. מסמנים **Public** (בתוכנית החינמית GitHub Pages עובד רק עם מאגר ציבורי. הקוד גלוי, אבל הנתונים והמצגות מוגנים ב-Supabase). לוחצים **Create repository**.
3. לוחצים **uploading an existing file**, גוררים פנימה את **כל התוכן של התיקייה** (לא את התיקייה עצמה) ולוחצים **Commit changes**.
4. **Settings** ‹ **Pages**. תחת **Build and deployment**: Source = **Deploy from a branch**, ‏Branch = **main**, תיקייה **/ (root)**, ולוחצים **Save**.
5. אחרי דקה-שתיים מופיעה הכתובת של האתר, בצורה `https://שם-המשתמש.github.io/courses/`.

## שלב 4: כניסה עם מייל וסיסמה

התלמידות נרשמות באתר פעם אחת, עם המייל שמסרו לך ועם סיסמה שהן בוחרות. אין צורך בחשבון Google.

1. ב-Supabase: **Authentication** ‹ **Sign In / Providers** ‹ **Email**.
2. מוודאים ש-**Enable Email provider** דלוק.
3. **מכבים את Confirm email** ולוחצים **Save**. (שירות המייל החינמי של Supabase לא שולח מיילים לתלמידות, ולכן בלי הכיבוי ההרשמה לא תושלם.)

אחר כך נכנסים לאתר ‹ "הרשמה בפעם הראשונה" ‹ נרשמים עם המייל שהכנסת בשלב 1 ‹ ומופיע תפריט הניהול.

**חשוב לדעת:**
- רק מיילים שהוספת ב"הרשאות" רואים קורסים. מי שנרשמת עם מייל אחר רואה "אין לך עדיין גישה".
- המערכת לא בודקת שהמייל באמת שייך למי שנרשמה. לכן כדאי לבקש מהתלמידות להירשם מיד אחרי שמוסיפים אותן.
- **שכחה סיסמה?** ב-Supabase: **Authentication** ‹ **Users** ‹ מוחקים את המשתמשת. היא נרשמת מחדש עם סיסמה חדשה, וההגשות שלה נשמרות.

## שימוש יומיומי

כל קורס הוא שם ורשימה של פריטים. כל פריט הוא מצגת, סרטון או תרגיל.

| מה רוצים | איפה |
|---|---|
| ליצור קורס | ניהול קורסים ‹ כותבים שם ‹ יצירה |
| להעלות מצגת | נכנסים לקורס ‹ ‎🖥️ + מצגת ‹ כותרת וקובץ HTML |
| להעלות סרטון | נכנסים לקורס ‹ ‎🎬 + סרטון ‹ כותרת וקובץ MP4 (עד 50MB) |
| להוסיף תרגיל | נכנסים לקורס ‹ ‎✏️ + תרגיל ‹ כותרת והוראות |
| לשנות סדר | החיצים ▲ ▼ ליד כל פריט |
| לבדוק הגשות | "הגשות" בתפריט הצד |
| לאשר תלמידות | "הרשאות" ‹ בוחרים קורס ‹ מדביקים מיילים |

כל פריט שמוסיפים מופיע לתלמידות מיד.

**הערות דובר במצגות:** את רואה אותן (מקש N). אצל תלמידות הן מוסתרות.

**סרטון גדול מ-50MB:** מכווצים אותו בתוכנה החינמית HandBrake (הגדרה Fast 720p30), ומעלים שוב.

## כדאי לדעת

- **פרויקט חינמי ב-Supabase נכנס להשהיה אחרי שבוע בלי שימוש.** אם האתר מפסיק לעבוד אחרי חופשה, נכנסים ל-Supabase ולוחצים **Restore project**. זה לוקח כמה דקות, והנתונים נשמרים.
- **שינוי באתר** (טקסט, עיצוב): מעלים שוב את הקובץ שהשתנה ל-GitHub (**Add file** ‹ **Upload files**). האתר מתעדכן תוך דקה.
- **שם האתר:** משנים את `siteName` בקובץ `config.js`.
- **מגבלות בתוכנית החינמית** (נכון לכתיבת המדריך): ב-Supabase יש 500MB לבסיס הנתונים ו-1GB לקבצים. זה מספיק למאות מצגות ותלמידות.
